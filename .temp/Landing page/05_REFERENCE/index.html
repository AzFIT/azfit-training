Branch Path Descriptions

Auto-Generate Path

The AI-powered FAB button allows users to skip directly to Exercise Review with pre-filled exercises based on their goal, experience level, and training frequency. All intermediate steps are populated with smart defaults.

Edit Path

Users can navigate backward to any previous step via the Back button or by clicking on completed step indicators in the progress bar. All previously entered data is preserved and displayed in the live preview sidebar.

Cancel / Discard Path

Available at any step through the Cancel button. A confirmation modal prevents accidental data loss. Users can also save their progress as a draft before leaving.

Focus Management

  • ☑ All interactive elements must have visible focus indicators using ring tokens
  • ☑ Focus order follows visual top-to-bottom, left-to-right reading order
  • ☐ Focus trapping in modals and dropdowns when open
  • ☑ Skip links provided for keyboard users to bypass navigation
  • ☑ Focus-visible used instead of focus to prevent mouse focus rings
  • ☑ Focus ring specification: 0 0 0 3px with brand color at 30% opacity
  • ☐ Tab index managed for custom components (toggle, slider, custom dropdown)

Screen Reader Support

  • ☑ ARIA labels on all icon-only buttons (menu, settings, user, FAB)
  • ☑ ARIA live regions for AI suggestion cards (aria-live="polite")
  • ☑ Progress announcements via aria-valuenow, aria-valuemin, aria-valuemax
  • ☑ Step indicator as role="navigation" with aria-current="step"
  • ☑ Collapsible sections use aria-expanded and aria-controls
  • ☐ Form errors announced with aria-describedby linking to error text
  • ☐ Loading states use aria-busy="true" with descriptive labels
  • ☑ Dynamic content (AI suggestions, preview updates) announced politely
  • ☑ Exercise cards use semantic <article> with proper headings
  • ☑ Day cards labeled with day name and training focus
